# OpenClaw First Impressions

**April 8, 2026**

A couple nights ago I was just doomscrolling Twitter/X and kept seeing OpenClaw everywhere.

The weird part? It apparently has more GitHub stars than the Linux kernel. That made me stop for a second. Like… okay, what is going on here?

So yeah, I gave it a try.

First thing I messed with was the WhatsApp integration. And honestly, it still feels a bit unreal. I can just send a message from my phone and it starts doing things on my computer. It’s like a remote control for my actual machine, except it talks back.

I’ve already used it a couple times to check PRs and go through GitHub issues while I wasn’t at my desk. Nothing crazy, but it worked. That’s the surprising part.

Right now I’ve got it running with a custom Qwen instruct model on Oracle Cloud, and it’s been… smooth? No weird lag, no random breaking (yet). Which I didn’t fully expect.

But honestly, I still don’t really *get* it.

I’m very much in that phase where every time I try something new, it does one more thing I didn’t expect. And I just sit there like, “okay… that’s kinda cool.”

It’s early. It’s a bit chaotic. I don’t fully understand it.

And yeah, I kind of like it that way.

Anyone else messing around with OpenClaw?
